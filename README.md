# Куда сегодня?

Демо-афиша Басманного района Москвы на React и Vite. Цены и расписание в `src/places.js` демонстрационные.

## Запуск в VS Code

Понадобится Node.js 22.12 или новее с npm. Откройте папку проекта в VS Code и выполните в терминале:

```sh
npm install
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Изображения загружаются с Unsplash.

## Сборка

```sh
npm run build
npm run preview
```

Готовый сайт собирается в `dist/`. Для публикации на GitHub Pages нужен деплой этого каталога. Относительные пути настроены в `vite.config.js`.

Фильтры «Сегодня» и «На выходных» объединяют предложения за оба периода. Ограничения по цене и компании дополнительно сужают результат. Форма для бизнеса сохраняет черновик в текущем браузере.
