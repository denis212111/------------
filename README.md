# Куда сегодня?

Статическая демо-афиша Басманного района Москвы. Карточки и расписание в `app.js` содержат демонстрационные данные.

## Запуск

Откройте папку в VS Code. В терминале проекта выполните:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Изображения загружаются с Unsplash.

Фильтры по дням складываются, а ограничения по цене и компании применяются одновременно. Заявка для бизнеса сохраняется как черновик в браузере. Статические файлы можно разместить на GitHub Pages из корня ветки `main`.
